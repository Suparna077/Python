# Python Utilities & Challenges 🐍🛠️

This repository contains a curated set of Python scripts and modules showcasing utility functions, file system operations, shell command automation, and scenario-based coding challenges.
It reflects hands-on problem solving and modular design principles for real-world scripting tasks.

## 📁 Folder Structure

| File | Description |
|------|-------------|
| `challenge_solution.py` | Contains Python solutions to coding challenges—ideal for interview prep and logic building. |
| `files_start.py` / `files_finished.py` | Demonstrates file read/write operations, directory traversal, and exception handling. |
| `ospathutils_start.py` / `ospathutils_finished.py` | Utility functions using `os` and `pathlib` for cross-platform path manipulation. |
| `shell_start.py` / `shell_finished.py` | Automates shell commands using Python’s `subprocess` module—great for DevOps scripting. |

## 🧠 Key Concepts Demonstrated

- File I/O and directory management
- OS-level path utilities (`os`, `pathlib`)
- Shell command execution via Python
- Modular coding with start/finished versions
- Scenario-based problem solving
